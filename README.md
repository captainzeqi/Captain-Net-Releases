Captain Net 是一款面向 Windows 用户的本地网络体检与局域网协同工具。它把 IP、DNS、WebRTC、代理、网络防护和多设备协作集中在一个桌面工作台中，适合需要排查网络问题、使用代理或在多台电脑之间共享工作环境的用户。

所有检测都在本机完成，结果不上传。

## 适合谁

- 经常使用 V2rayN、Clash、mihomo 等代理软件的用户
- 需要排查 DNS 泄露、WebRTC 泄露、IPv6 绕过和网络分流的用户
- 远程办公、开发、跨境访问或需要多地区网络连通性测试的用户
- 家庭、工作室和小型办公室中使用多台电脑的用户
- 希望一套键盘鼠标控制多台电脑，或在设备之间共享剪贴板、文件和打印机的用户

## 核心功能

### 网络体检

- **网络测速**：分别测量国内直连和海外出口的下载速率，各自显示该条链路真正使用的出口 IP
- **IP 检测**：出口 IP、ASN、运营商、地理位置和离线地图标记
- **IP 评分**：纯净度、风险、代理特征、端口和多源地理信息
- **网络连通**：中国、日本、美国和全球站点延迟矩阵
- **全球 Ping**：节点延迟、丢包、抖动和路由追踪（每跳三探针取最小值）
- **DNS 泄露**：与在线检测网站同源的权威回显方法，区分解析器出口与 EDNS 客户端网段，并能识别 DNS 应答污染
- **WebRTC / STUN**：公网映射地址、本机接口地址和泄露风险
- **服务状态**：云服务、开发平台和 AI 服务连通性看板
- **AI 风险检测**：Claude、ChatGPT 出口链路和可用性检查
- **一键全量体检**：串联全部检测并生成可导出报告

延迟测量会识别 TUN 模式代理：这类代理在本机直接应答 ICMP 和 TCP 握手，会让所有节点显示成 0ms。检测到之后会改用必须与源站往返的 TLS 握手计时，报出真实链路延迟。

### 网络防护

- 检查网卡 DNS 配置和 Chromium WebRTC 策略
- 保存修改前的原始配置
- 一键应用安全建议
- 一键恢复到修改前状态
- 支持隐藏 IP，方便截图和录屏

### 代理诊断

- 识别 V2rayN、Clash、mihomo、sing-box 等代理进程
- 检查系统代理、监听端口、TUN 虚拟网卡和运行态线索
- 读取常见配置目录和便携版安装目录
- 管理员深度扫描进程路径、命令行和配置参数
- 只读诊断，不自动修改代理软件配置

### 无界键鼠

- 一套键盘鼠标控制所有已配对设备，任意设备都能作为控制端，无需设置主设备
- 鼠标移到屏幕边缘即切换到相邻设备，键盘跟随当前控制端
- 自动检测多显示器：每块屏幕都是布局中的独立节点，可分别摆放
- 网格化设备布局，拖动即同步到所有设备，设备再多也不会重叠
- 任意时刻只有活动设备显示光标，其余设备自动隐藏
- 切换设备时自动补齐按住的修饰键，不会出现 Ctrl 卡住
- 光标可见性有独立看门狗守护：只要不处于跨设备控制状态，光标最多 1 秒内必定恢复；应用异常退出后下次启动也会自动修复，设置页和托盘菜单还提供“恢复鼠标光标”手动兜底

### 局域网打印机

- 在连接打印机的设备上单独开启共享，其他设备自动看到
- 任意设备上传文件并提交打印
- 跨设备打印记录同步

### 局域网传输

- 拖拽或选择文件、文件夹即可共享
- 所有已配对设备看到同一份共享清单
- 任意设备点击下载，可自行选择保存路径，文件夹会还原原有目录结构
- 共享只发清单，点下载时才按需传输，文件始终留在发布它的设备上

### 剪贴板同步

- 已配对设备之间自动同步剪贴板文本
- 截图和复制的图片同样跨设备同步，PNG 无损传输，同时提供位图和 PNG 两种格式，画图、Office、浏览器都能直接 Ctrl+V
- 复制文件后其他设备可直接 Ctrl+V 粘贴，超过阈值的大文件会先询问
- 按系统剪贴板序号触发同步，内容没变不会反复读取；读写都带重试，被输入法或其它程序短暂占用时不会漏同步

### 应用体验

- 关闭窗口后驻留系统托盘继续运行，从托盘图标恢复，右键菜单退出
- 启动时自动检查新版本，左下角弹出提示，点“立即重启更新”即自动下载、替换并重新打开
- 更新一步升到最新版本，新版本下载到应用所在目录，替换完成后自动删除旧版本并重新启动

局域网发现使用 UDP `45678`，协同传输使用 TCP `45679`，鼠标键盘低延迟输入使用 UDP `45679`。如果 Windows 防火墙拦截通信，请允许 Captain Net 访问本地网络。

## 使用流程

1. 从 Releases 下载对应系统版本并解压。
2. 启动 Captain Net，先运行“IP 检测”或“一键全量体检”。
3. 需要网络修复时进入“网络防护”，先检查备份信息，再应用建议。
4. 需要代理排查时进入“代理诊断”，必要时点击“管理员深度扫描”。
5. 多设备协同时，在“无界键鼠”搜索并配对其他设备，按真实摆放拖动设备布局，再打开键鼠共享。
6. 连接打印机的设备在“局域网打印机”开启共享，其他设备即可上传文件打印。
7. 需要传文件时进入“局域网传输”，拖入文件或文件夹，其他设备选择路径下载。

## 隐私与安全

- 网络检测结果默认保存在本机 `%AppData%\CaptainNet`。
- 应用不上传检测报告，不依赖原参考网站运行。
- 管理员权限只在深度代理扫描、网络配置应用、打印机共享等明确操作时请求。
- 局域网功能只对**已配对**的设备开放，配对需要用户确认。
- 接收到的共享文件按相对路径还原时会过滤 `..`，不会被写到所选目录之外。
- 局域网协同当前建议只在可信网络中使用；生产部署前应继续完善 TLS 配对、输入控制权限和代码签名。

## 开发与构建

### Windows

需要 .NET 8 SDK：

```powershell
dotnet build -c Debug
dotnet publish NetCoffee.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

推送 `v*` 格式的标签后，`.github/workflows/release.yml` 会构建便携版并同时发布到本仓库和公开发布仓库 [`Captain-Net-Releases`](https://github.com/captainzeqi/Captain-Net-Releases)。应用内的自动更新只读取公开发布仓库，因此源码仓库可以设为私有。

发布到公开仓库需要在本仓库配置 `RELEASE_REPO_TOKEN`（对发布仓库有 Contents 写权限的令牌）；未配置时该步骤会自动跳过。
