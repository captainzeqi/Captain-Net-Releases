Captain Net 是一款面向 Windows 的本地网络诊断与局域网协同工作台：把 IP、DNS、WebRTC、代理、网络防护、跨设备键鼠、文件传输、屏幕广播和局域网聊天集中在一个桌面应用中。

检测结果、聊天记录、设备备注和历史数据默认只保存在本机，不上传网络；局域网功能仅面向用户确认过的已配对设备。

## 适合谁

- 使用 V2rayN、Clash、mihomo、sing-box 等代理软件、需要排查分流问题的用户
- 需要检查 DNS 泄露、WebRTC 泄露、IPv6 绕过和真实链路速度的用户
- 远程办公、开发、跨境访问、家庭或小型办公室中的多台 Windows 设备用户
- 希望共享一套键盘鼠标、剪贴板、文件、屏幕或打印机的用户

## 功能总览

### 网络诊断

- **网络测速**：分别测量国内与海外链路的真实下载速度，并显示各自的出口 IP
- **IP 检测**：出口 IPv4/IPv6、ASN、运营商、地理位置与地图定位
- **IP 评分**：纯净度、代理/VPN/Tor/机房风险、端口与多源地理信息
- **网络连通**：中国、日本、美国和全球站点的握手延迟矩阵
- **全球 Ping**：延迟、丢包、抖动和路由追踪
- **DNS 泄露**：系统 DNS、真实递归解析器出口与污染风险
- **WebRTC / STUN**：公网映射地址、本机网卡地址和泄露风险
- **服务状态**：云服务、开发平台与 AI 服务可用性
- **AI 风险检测**：Claude、ChatGPT 出口链路和端点检查
- **一键全量体检**：串联全部检测并导出报告
- **网络防护**：备份 DNS/WebRTC 原配置，一键应用建议或恢复
- **代理诊断**：只读检查代理进程、系统代理、端口、TUN 网卡和配置线索
- **隐藏 IP**：所有页面统一切换 IP 打码与完整显示，适合截图/录屏

### 局域网协同

所有协同功能都在左侧导航中独立列出，先在「无界键鼠」搜索并配对设备。

#### 无界键鼠

- 鼠标移到屏幕边缘即可切换到相邻设备，任意设备都可作为控制端
- 自动识别多显示器，每块屏幕都是独立布局节点
- 拖动 Canvas 设备布局即可同步到其它设备
- 配对设备之间同步文本、截图、图片和可粘贴的文件列表
- 光标隐藏有独立看门狗，异常退出后也会自动恢复
- **设备间声音同步**：每台设备各有一个「共享本机声音」开关，打开后扬声器输出实时同步给所有已配对设备；其余设备默认自动接收并播放，无需每次确认
- 播放端带抖动缓冲和延迟校正：网络波动后会主动追平进度，不会越听越滞后
- 共享期间本机不播放其它设备的声音。环回采集抓的是整个扬声器输出，边放边采会把对方的声音原样发回去形成回声，因此同一台设备上「共享」与「收听」互斥

#### 局域网传输

- 拖拽或选择文件/文件夹后共享，已配对设备看到统一清单
- 文件按需下载，接收端可选择保存位置并还原原目录结构
- 多文件任务显示单文件与整体进度，并保留传输历史
- 中断传输支持断点续传
- 临时分片存放在隐藏的 `.captain-partial` 目录，完成后校验字节数并恢复原始文件名与扩展名（包括 `.exe`、压缩包、媒体和文档），不会把 `.part` 当成最终文件

#### 屏幕查看授权

- 发起查看时，被查看设备会弹出置顶授权框，未同意前对方连不上画面
- 授权时可分别勾选「同步扬声器声音」和「允许对方控制键鼠」，两项默认都关闭
- 只授权查看的情况下，查看方可在观看过程中单独「申请控制权」，被查看方会再次收到授权框
- 关闭查看窗口或点顶部提示的「取消屏幕查看」都会立即收回授权，对方需重新申请
- 只要本机屏幕正在被查看或广播，页面顶部始终显示共享提示，并标明是否含声音、是否已交出键鼠控制
- 跨设备截图同样需要对方当场同意；已授权查看时才直接截取，其余情况每次都单独询问

#### 屏幕广播

- 单独的「屏幕广播」页面，可勾选设备或一键全选
- 发起广播后，接收端桌面弹出置顶邀请，用户明确选择「接受查看」或「拒绝」
- 发起者实时看到等待回应、已接受、正在收看、已拒绝和已结束状态
- 广播是单向的：观众只能观看，不能反向控制发起端设备
- 发起端可选「同步本机扬声器声音」，采集的是扬声器输出而非麦克风；观众端可自行静音
- 广播评论：发起者和所有观众都能留言，参与同一场广播的设备看到同一份评论
- 发起者可随时结束全部广播；结束后观众端查看窗口自动关闭
- 被查看端页面顶部显示正在查看的设备，并可一键取消屏幕查看

#### 局域网聊天

- 单独的「局域网聊天」页面，支持已配对设备间双向文字对话
- 支持发送任意格式文件和文件夹，聊天区保留文件消息记录
- 设备备注名仅保存在本机，不会覆盖对方设备名称
- 每个对话可单独一键清空；清空只影响当前设备，不会删除对方记录
- 聊天记录保存在 `%AppData%\CaptainNet\chat`，不上传公网

#### 局域网打印机

- 在连接打印机的设备上开启共享，其他设备自动发现
- 任意已配对设备提交打印文件
- 打印记录跨设备同步

## 使用流程

1. 从 [Releases](https://github.com/captainzeqi/Captain-Net-Releases/releases/latest) 下载 Windows x64 便携版。
2. 双击 EXE 运行，无需安装和 .NET 运行时。
3. 先运行「IP 检测」或「一键全量体检」。
4. 多设备协同：打开「无界键鼠」，搜索并完成双方配对。
5. 传文件：打开「局域网传输」，共享文件或文件夹。
6. 广播屏幕：打开「屏幕广播」，勾选设备并等待对方接受。
7. 聊天沟通：打开「局域网聊天」，选择设备后发送文字、文件或文件夹。

## 隐私与安全边界

- 网络诊断结果、聊天记录、设备备注、传输历史默认写入本机 `%AppData%\CaptainNet`。
- 应用不上传检测报告，不依赖在线参考网站才能打开；联网只用于执行需要网络的检测和检查更新。
- 局域网功能只对已配对设备开放，配对需要用户确认。
- 接收文件会过滤盘符、`..` 和非法路径字符，避免写到用户选择目录之外。
- 接收文件先写入隐藏临时目录，校验完整长度后再恢复正式文件名。
- 当前局域网协同面向可信内网；使用屏幕查看、远程控制和文件接收时，请只配对可信设备。生产环境部署仍建议加入 TLS 配对、细粒度权限和代码签名。

## 网络端口

- UDP `45678`：设备发现与心跳
- TCP `45679`：协同控制、文件与聊天消息
- UDP `45679`：低延迟鼠标/键盘输入
- TCP `45680`：屏幕查看/广播视频流
- TCP `45681`：屏幕广播的扬声器音频流

如被 Windows 防火墙拦截，请允许 Captain Net 访问专用网络。

## 开发与构建

需要 .NET 8 SDK：

```powershell
dotnet build -c Debug
dotnet publish NetCoffee.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

推送 `v*` 标签后，`.github/workflows/release.yml` 会构建 Windows 便携版，并发布到源码仓库和公开发布仓库 [Captain-Net-Releases](https://github.com/captainzeqi/Captain-Net-Releases)。应用内更新只读取公开发布仓库，因此源码仓库可以保持私有。
